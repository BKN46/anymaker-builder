# 普通传动皮带

## 范围与证据

2026-09-28 只读检查本机游戏 `bin/game.gcl`、四种轮子的 ROM 定义、`textures/belt.txtr`，以及 `test-vehicle/vehicle.data` 中 vehicle 553 的六轮回路。游戏指纹、9 个函数签名/偏移/代码哈希、10 个常量、组件定义与纹理哈希见 [证据摘要](evidence/belts.json)。

普通皮带和履带共用 `vehicle_belt.rebuild`，但生成方式不同。普通皮带的实体由程序连续生成；[履带](13_TRACKS.md)则逐片实例化 Mesh。此次采用 `rebuild(vehicle_belt, vehicle)` 的长函数（`0xf39fcf`），网络收集在另一个同名 overload `rebuild(vehicle)`（`0xf486e8`）。

| 组件 | 半径（世界单位） | 原始端口 |
| --- | ---: | ---: |
| `pulley_wheel` | 0.04 | 0 |
| `engine_wheel` | 0.10 | 0 |
| `engine_wheel_b` | 0.155 | 0 |
| `engine_wheel_c` | 0.267 | 0 |

四种组件均使用 `logic_nodes[].type: belt`。皮带轮心取逻辑节点的扩展位置经组件变换后的结果，不能使用端口外伸点。第一轮的局部 +Z 给出轮轴；游戏的切线离散为 32 个方向，角度为 `-2π × index / 32`，signed distance 的搜索阈值为 0.0001。`reverse` 为保存的布尔属性；相邻轮方向相反时接点翻转半周，反向惰轮按相反方向绕行。

带截面宽 0.056、厚 0.012 世界单位（56 mm × 12 mm），每截面 8 个顶点、四个面，各面保留独立法线。游戏 UV 的 V 固定为 0，U 的目标密度为 16；原算法在圆弧两端均分配一步弦长，再加直线距离，最后调整为整数次重复。编辑器保留该分配和闭合接缝。

原始纹理是 TXTR v2 RGBA8，32×32，6 级 mip。`scripts/build-belt-texture.mjs` 校验全部 mip 尺寸/长度，用原始第一层 RGBA 生成确定性 PNG，元数据保留源/产物 SHA-256。发布 PNG 位于 `public/assets/textures/belt.png`，109 字节；浏览器不依赖游戏目录。Three.js 根据 PNG 生成 mip，当前光照和材质参数并非游戏着色器的完整复刻。

## 当前行为

- 导入普通 `belt_links` 后生成连续实体；连接工具选择 Belt，两轮之间一条边即可形成闭环。多轮沿保存的无分叉闭环顺序绕行，保留内凹反向惰轮。
- 支持四种轮径混用；轮轴需平行、轮心需共面。缩放轮、错误端口、普通皮带/履带混接、分叉及无法形成切线时明确诊断。未闭合的合法引用仍保留为诊断线，可以继续补全。
- 移动、旋转、镜像或修改任意轮的 `reverse` 会重建整环，包括与第一条边不相邻的轮子。修改属性和连接沿用完整的撤销/重做。
- 显示连接中的皮带开关控制实体显示，原生参考预览保留实体；隐藏任意轮时整圈隐藏。
- 端点仍使用原始逻辑节点索引；definition override 不能改变端口索引的含义。工程与原生保存仍保存连接及轮子属性，不保存派生网格或 GPU 对象，不改变 schema。
- 切线搜索最多 64 次；整场景截面最多 16384。这是编辑器的内存分配限制，不是已验证的游戏上限。

## 实现与资源生命周期

- `src/editor/belt-profiles.js`：四类轮径、端口与截面常量。
- `src/editor/belt-path.js`：纯数据网络、切线与采样；不依赖 DOM 或 Three.js。
- `src/editor/belt-view.js`：闭合 BufferGeometry、法线/绕序和纹理加载。
- `src/main.js`：增量视图缓存、连接工具、双语诊断、纹理懒加载。纹理由应用持有并跨实体共享；重建/删除只释放每个皮带自己的几何及材质，不销毁共享纹理。页面生命周期结束由渲染上下文回收。
- `tests/belts.test.js`、`tests/belt-fixtures.js`：轮径/端口、真实回路、反向、镜像/旋转、尺寸/绕序/UV、异常网络、分配限制、原生回读、历史与纹理像素。
- `tests/browser/editor.spec.js`：原生六轮样本、反向/移动刷新、撤销重做、显隐/参考预览、导出回读、工具创建及双语诊断。

真实回路顺序为 `27 → 30 → 14 → 29 → 31 → 28 → 27`，14 为发动机轮，31 为反向惰轮；当前得到 60 截面、周长约 1.8470701731 世界单位。测试只读提取这六轮及六条边，原样本不修改。

可复核命令（仓库根目录）：

```powershell

node scripts/build-belt-texture.mjs <Anymaker/rom>
npm run check:assets

npm run test:browser:editor
```

## 未验证范围

当前为建造姿态的静态皮带。游戏运行速度、纹理运动相位、发动机/轮子的动态转动、张紧与动力学未实现；游戏着色器、同机位画面对照和导出后的真实游戏加载未验收。几何、纹理指纹、测试通过不等于游戏兼容或整体视觉 1:1。
