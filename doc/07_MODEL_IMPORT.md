# 3D 模型解析

## 交互与当前实现

右侧 **资源与校验 → 3D 模型解析**：选择本地 GLB、OBJ 或 STL，查看源顶点记录与三角面数量；调整简化和整体等比缩放，查看最终节点、梁、面板以及占地。确认后替换当前载具，一次撤销恢复原工程。取消、解析失败和调整参数均不修改当前工程。

- 简化滑条共 13 档，目标顶点数依次为 **250、230、210、190、170、150、130、110、90、70、50、40、30**，默认约 150。前 10 档仍重点覆盖 70–250；后三档降低外壳截面数，提供更粗略的轮廓。界面同时显示目标、简化后的顶点和最终格点节点数。截面按八个顶点一圈分配预算，格点合并与退化清理会改变实际数量；简单平面不会被人为补点。
- 三轴首末深度交集形成实体包络，在最长轴 56 个体素的固定网格上进行两轮低通滤波；移除微小孤岛，填充封闭空腔。内部座椅、底盘等不再各自生成结构，细小凸起被滤除。
- 对体积模型沿最长轴采样凸八边形外轮廓，将相邻截面连接成共面四边面，两端封口。前 10 档至少保留 10 个截面；额外的 50、40、30 目标档分别允许 6、5、4 个截面。统一截面边方向并在格点上重建；当模型该轴整体足够宽时，极薄的端部截面至少保留 6 格宽度，转角至少保留 2 格，避免格点吸附后产生折叠面和单格短梁。明显凹槽、孔洞、截面内部的分离零件及空隙会被外壳包络合并；这个模式保留主要外形。
- 开放共面模型（包括倾斜面）沿用平面几何减面，保持开放形状；密集输入先聚类至最多 2,048 顶点，再进行边折叠。相邻三角形在共面、凸且方向一致时合并为四边面；必要时允许每轴最多一格的局部校正，已接受的四边面锁定，邻面不得翻转或塌缩。无法合法合并的面保留三角形。
- **对称模式**默认关闭，可选 X / Y / Z 方向，分别对应穿过原模型包围盒中心的 YZ / XZ / XY 平面。中心平面吸附到最近的 8 cm 格点平面；Y 方向使用模型中部，不以地面为对称面。开启后对外壳截面与其镜像取平均，成对拟合范围、角点和截面位置；开放平面保留中心正向半侧并镜像补齐，两侧可能与原模型轮廓不同。关闭后恢复原始简化结果，不修改线程中的模型缓存。
- 对称约束用于最终节点，包括缩放和格点吸附后的结果；四边面合并在此模式下禁止单点微调，避免破坏对称。仍优先合并合法四边面，但梁和面板的分割方式不保证逐面对称。实际节点数和占地按对称处理后的结构更新；开放平面的裁切可能增加接缝节点。
- 缩放滑条为 0.01×–100×，默认 1×。**1× 表示应用 GLB 场景变换后，原模型最长边归一化为 4 m**，不是原文件单位到游戏单位的已验证映射。所有档位共用原始包围盒作为缩放基准；以 X/Z 中心和最低 Y 为定位基准。最终坐标吸附到 8 cm 整数格。
- 占地按生成后剩余节点计算 X × Z，并单列 Y 高度；每轴节点跨度额外加一格，计入梁的截面厚度。因此源模型最长边 4 m，满跨度梁的占地可为 4.08 m。现有主视口 HUD 使用节点跨度，尚不包含这额外一格，两者定义不同。
- 共享顶点生成节点，沿最终三角/四边面的周边生成梁，**不生成四边面内部的三角化对角梁**。面板默认开启，使用外壳绕序计算法向，可整体翻转。四边面保持四节点记录，未修改工程 schema 或放宽共面校验。
- SVG 线框预览来自最终格点结构，可拖动或用方向键旋转；它显示节点中心线，不显示梁截面、材质或面板着色。
- 中英文文案随编辑器语言设置切换。文件、解析网格、线程缓存、控件临时值不进入工程快照；只保存生成后的标准拓扑。

## 模块与格式边界

| 模块 | 职责 |
| --- | --- |
| `src/assets/model-import.js` | GLB 场景与几何读取；Three.js OBJ/STL 几何读取及输入边界 |
| `src/assets/model-shell.js` | 深度包络、低通滤波、空腔/孤岛处理，开放平面减面 |
| `src/editor/model-shell-sections.js` | 外轮廓截面采样与共面四边壳体 |
| `src/editor/model-symmetry.js` | 截面镜像平均、开放面裁切和绕序反射 |
| `src/editor/model-quads.js` | 格点共面四边面合并和邻面保护 |
| `src/editor/model-mesh.js` | 包围盒、几何法向、顶点/面重映射 |
| `src/editor/model-import-settings.js` | 13 档顶点预算与默认档位 |
| `src/editor/model-conversion.js` | 格点合并、去重、法向、占地及纯数据拓扑 |
| `src/editor/model-import-worker.js` | 后台解析、简化；最多缓存三个简化档位 |
| `src/editor/model-import-tool.js` | sidebar 控件、请求版本与取消、预览、提交回调 |
| `src/locales/model-import-en.js` | 工具中英文映射 |
| `src/main.js` | 校验、准备渲染对象、替换工程、历史及相机聚焦 |

GLB 支持 glTF 2.0 内嵌 BIN、默认场景的静态节点层级、matrix/TRS、重复 Mesh 实例、Float32 POSITION、可交错 bufferView、8/16/32 位索引、无索引三角形、strip/fan。材质、纹理、相机、动画不参与转换，也不加载引用 URL。外部 buffer、稀疏 accessor、压缩/扩展几何、蒙皮、morph target 和非面图元明确报错；首版未接入 Draco/Meshopt 解码器。

OBJ 使用 Three.js 的几何解析，不读取 MTL 或纹理；支持正/负索引和解析器的多边形扇形三角化，复杂凹多边形应先在建模软件三角化。STL 支持 ASCII 和二进制，面方向采用顶点绕序；不会根据法线字段修复错误绕序。

文件限制为 32 MiB；解析上限 50 万顶点记录与 50 万三角面，OBJ/STL 还限制展开后的顶点记录数量。生成上限 5,000 节点、10,000 梁、4,000 个最终面；超限展示计数并阻止确认，由用户提高简化档位。限制属于本工具的内存与交互预算，不是游戏限制。未建立低性能机器的帧率保证。

解析验证长度、计数、有限坐标、索引和节点层级循环。选择其他文件或取消会终止旧线程；滑条计算期间禁用确认，丢弃旧参数结果。所有逻辑随静态站点发布，Worker 地址由 Vite 生成并适配站点子路径。

## 验证

- `npm run check`：116 项单元测试及生产构建通过。覆盖层级/反射、非法 GLB、OBJ 负索引、ASCII/二进制 STL、内部几何剔除、小凸起滤除、倾斜开放面、预算档位、共面四边面、闭合边界、无内部对角梁、格点、占地与法向，以及窄端截面和原生导出绕序。另有非对称壳体三种轴向排列、X/Y/Z 对称、半格取整、多档位/缩放、中心接缝、开放面法向及关闭后恢复测试。
- 完整 `npm run test:browser:editor` 中的 3D model 三条流程通过：三格式选择、缩放、关闭/翻转面板、对称、确认、撤销/重做、语言、取消与坏文件保护，以及指定真实样本。可用 `-- --grep "3D model"` 单独复跑这些流程。
- 指定外部样本可复现真实模型流程；样本不复制进仓库：

```powershell
$env:ANYMAKER_MODEL_SAMPLE = '<本地模型路径>'
npm run test:browser:editor -- --grep '3D model'
```
